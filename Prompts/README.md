# Reusable prompts

Use the prompts in order for an existing project. They are tool-neutral and can be pasted into Codex, GitHub Copilot, or another coding agent. Replace bracketed values. Each prompt is deliberately evidence-first.

- `00-discover-project.md` - read-only inventory before drafting.
- `01-initialize-from-sources.md` - create the initial business and technical docs from code and existing documents.
- `02-review-grounding.md` - audit every claim against sources.
- `03-plan-a-change.md` - prepare a change record before implementation when useful.
- `04-update-after-change.md` - update current docs after implementation and verification.
- `05-review-doc-access.md` - verify that agents can find the project knowledge base.
